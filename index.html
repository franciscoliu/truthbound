OUR GOAL

Keep autonomous agents
faithful to the task.

Software / Research / Operations

01 / MOTIVATION

A good score can hide
unfinished work.

Agents increasingly work toward goals: finish a task, pass a check, close a case. A measure of success can miss whether the underlying work was done correctly.

We want to examine the gap between the objective an agent pursues, the actions it takes and the account it gives.

01

Taking a shortcut

An agent changes a protected check to get a passing result, without permission.

02

Misreporting the outcome

An agent reports that an action completed even though the execution record shows it failed.

03

Bending to a competing objective

A target such as speed or cost control pulls behavior away from the task's stated requirements.

Examples of behavior to test. Understanding intent is a separate question.

02 / APPROACH

First focus: before a model,
prompt or workflow change.

From a failure to a
better release decision.

We are developing a workflow that starts with a team's own task requirements, sandbox and execution evidence.

  1. 01

    Define the task

    Agree on the requirements, permitted actions and acceptance criteria.

  2. 02

    Check the evidence

    Compare agent reports with logs, artifacts and independent outcome checks.

  3. 03

    Vary the pressure

    Test competing objectives while keeping the authorized task fixed.

  4. 04

    Test the repair

    Turn confirmed failures into reproducible cases. Check candidate fixes on held-out tasks.

↳

The standard is practical: find useful problems or improve repair decisions within the same testing and review budget as the team's existing checks.

03 / RESEARCH FOUNDATION

Built on
KnownLieBench.

KnownLieBench studies misleading behavior under conflicting incentives. A separate neutral probe checks whether a model can identify a documented entitlement before its customer-service behavior is evaluated.

The study spans eight customer-service domains. These are controlled simulations; extending the method to enterprise workflows is the work ahead.
