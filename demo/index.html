METHOD AND LIMITS

How it was produced

    Limits

    • One policy, seven generated cases, a handful of runs. A demonstration of the mechanism, not a benchmark.
    • Models answer at temperature 0 but are not fully deterministic. The low-cost model failed the same three cases in all three unguarded runs; other models ran once.
    • Before these runs one pipeline bug was fixed by hand: the step that lists the reasons a customer may state had missed "health" and "weather". Only post-fix runs are shown.
    • The guardrail ran in enforce mode. In every run the agent corrected itself after one rejection; the override path never fired.
    • Two of the seven cases describe the same situation (economy, no insurance, change of plan). Both are kept because the pipeline produced them.
    • Act I is a simulated pre-launch scenario. The agent runs are real; the "shipped" framing is not a customer deployment.
